**Open Source Hall of Fame**

## Prompt Used

```text
Act as a senior front-end developer and UI/UX designer with 20 years of experience.

I am building a modern developer conference landing page called "DevConf 2026" using only HTML and CSS (no JavaScript or frameworks).

Create a brand-new section called "Open Source Hall of Fame" that highlights outstanding open-source projects and contributors in the developer community.

Requirements:
- Follow a premium dark theme that matches the rest of the DevConf 2026 website.
- Add a centered section heading and a short descriptive subtitle.
- Design a modern grid layout with multiple project cards.
- Each card should include:
  - Project category/tag
  - GitHub stars
  - Project name
  - Short project description
  - Contributor information with avatar and role.
- Make one featured card larger than the others.
- Use clean typography, subtle borders, and a professional developer-focused design.
- Write semantic HTML5 and clean, organized CSS.
- Do not use JavaScript, Bootstrap, Tailwind CSS, or external UI libraries.
- Ensure the section feels unique, modern, and consistent with the DevConf 2026 landing page.
```
